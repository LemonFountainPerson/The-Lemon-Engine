# The LemonEngine
**Liam Fuentes Pessoa**
_________________________________________________


Current Version: 0.11

The Lemon Engine is a 2-D game engine made entirely in C and uses the SDL3 library and its various associated libraries (SDL_NET, SDL_MIXER, SDL_TTF).
Inspired by many of the greats such as Source, GameMaker and Unity.


Features include:

	*A Game Event system that controls triggerable events and is a sahred communication method for many parts of the engine

	*Component add-ons for Objects to modularly expand an Objects' functionality

	*A sound system that organises sounds into channels and can load larger sound files asynchronously

	*An animation system that can be entirely utilised via LemponScript files

	*An intuitive level-based format for constructing environments or scenes via LemponScript files

	*A built-in cutscene management system that can create dynamic scenes with branching execution via LemponScript files

	*Basic networking, allowing one instance to act as a Server while other instances can join as clients, syncing Game Events, variables and Objects

	*An in-engine developer console to make runtime debugging easy

	*And more!
