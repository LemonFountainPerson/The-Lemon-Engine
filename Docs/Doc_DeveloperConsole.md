# Developer Console
_________________________________________________

![V0.11 Console Image](Images/V0.11Console.png)
Developer Console as of V0.11.

## How to use

Press the 'LMN_CONSOLE_OPEN' key (by default bound to the Grave key on UK/US keyboards, under the escape key) to open/close the console.
Click on the upper section to allow for scrolling through the console history, and click on the bottom section to allow for typing commands.
When focused on the bottom section, the up/down arrow keys cycle between the last entered commands. 
Like in [LemonScript](Doc_LemonScript.md), phrases inside of speech marks will be considered all one argument (E.g: "phrase here").
Finally, simply type and hit enter to execute commands.
