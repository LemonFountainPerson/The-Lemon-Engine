# ConsoleVariableType

## Definition
```
typedef enum ConsoleVariableType
{
	CONVAR_INT,
	CONVAR_FLOAT,
	CONVAR_BOOL,
	CONVAR_STRING
} ConsoleVariableType;
```

## Description
This enum defines the type of data a [ConsoleVariable](Data_ConsoleVariable.md) stores.


## Version
Available since V0.11.
