# Lemon Script
_________________________________________________

Current version: 1

LemonScript is the language used within various script files for the Lemon Engine used to describe instructions for the 
given task. For example LemonScript is used for level data files for describing level creation, cutscene files for scene
playback and animation files for creating [Spritesets](Data_SpriteSet.md) and [Animations](Data_Animation.md) for [Objects](Data_Object.md).

Depending on the type of file you are working with, the available instructions will change, but the general syntax will 
stay the same.
