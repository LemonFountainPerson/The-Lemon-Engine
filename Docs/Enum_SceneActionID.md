# SceneActionID

## Definition
```
typedef enum SceneActionID
{
	SCENE_END,
	SCENE_REPEAT,
	SCENE_REPEAT_UNTIL,
	SCENE_REPEAT_WHILE,	// Just the opposite of 'SCENE_REPEAT_UNTIL'
	SCENE_SKIP_INSTRUCTIONS,
	SCENE_IF_STATEMENT,
	SCENE_SWITCH_CUTSCENE,
	SCENE_TRIGGER_GAME_EVENT,
	SCENE_DISABLE_PLAYER,
	SCENE_ENABLE_PLAYER,
	SCENE_WAIT,
	SCENE_CHANGE_VARIABLE_BY,
	SCENE_SET_VARIABLE_TO,
	SCENE_SAY_TEXT,
	SCENE_PLACE_INVISIBLE_WALL,
	SCENE_CREATE_ACTOR,
	SCENE_RELEASE_ACTOR,
	SCENE_SHOW_ACTOR,
	SCENE_HIDE_ACTOR,

	SCENE_ANIMATE_ACTOR_WAIT,
	SCENE_SET_ACTOR_SPRITE,
	SCENE_SET_ACTOR_POS,
	SCENE_MOVE_ACTOR,
	SCENE_MOVE_ACTOR_X,

	SCENE_MOVE_ACTOR_TO,
	SCENE_ROTATE_ACTOR,
	SCENE_SET_ACTOR_DIRECTION,

	SCENE_PLAY_SOUND,

	SCENE_SET_CAMERA_POS,

	SCENE_MOVE_CAMERA,

	SCENE_SET_CAMERA_ZOOM,
	SCENE_CHANGE_CAMERA_ZOOM,
	SCENE_CHANGE_CAMERA_ZOOM_TO,
	SCENE_ACTION_COUNT
} SceneActionID;
```

## Description
This enum defines a [SceneAction's](Data_SceneAction.md) behaviour. Some action IDs will perform an 
action on a specific [Object](Data_Object.md) while others regulate a scene's control flow.

## Version
Available since V0.08.
